# Cleartrip Automation Project with Playwright

This project uses [Playwright](https://playwright.dev/) and JavaScript to automate test cases for [Cleartrip.com](https://www.cleartrip.com/).

## 🚀 Project Overview

Automated UI tests for Cleartrip.com covering:

1. **Roundtrip Flight Search**
2. **Navigation to Buses and Hotels Pages**

## 🧪 Test Cases Implemented

### ✅ Test Case 1: Roundtrip Flight Search
- Select "Round Trip"
- Enter valid origin and destination
- Choose departure and return dates
- Click "Search Flights"
- Verify that results are displayed successfully

### ✅ Test Case 2: Buses and Hotels Navigation
- Click on the "Buses" link
- Verify Buses page loads successfully
- click on "Hotels"
- Verify Hotels page loads successfully

## 🛠️ Tools & Tech Used

- **Playwright** (JavaScript)
- **Node.js**
- **VS Code** for development
- **Git/GitHub** for version control

## Run all tests using
 -npx playwright test

## To Open reposrts
- npx playwright show-report / npx playwright show-report reports
